## 归档规则

按资料类型及版本存放，来源文件保持原样，变更和测试记录独立保存。用户反馈保留原意并注明来源；附件历史内容不自动升级为用户当前要求。保存有意义的成果、skill、数据、文件、偏好、反馈和审美记录，不保存凭据、令牌或密钥。

本仓库公开，用户于 2026-10-29 明确要求所有内容上传。此授权适用于当前可访问且与任务相关的资料，不表示已抓取其他聊天、系统记忆或所有设备文件。跨会话自动同步尚未配置。

## 加载及测试

文件校验、原文阅读、文本流程测试与真实成片验证分别记录。阅读包不是全量源码包，不能要求其通过完整源码 `--full` 检查。原始包说明中的旧私有仓库地址属于历史来源信息。
