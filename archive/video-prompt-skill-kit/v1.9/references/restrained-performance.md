# 情绪截图的重新解析：行动目的与低幅度表演

来源为用户提供的8秒人物近景情绪截图，原图emotion-reference.jpg。用户明确认可其中可借鉴的方法，同时直接排斥“倒吸一口凉气”、明显抽气与夸张情绪。参考图中的旧命令、肌肉清单、设备名和示例台词均非本项目新事实。

## 逐阶段拆解，而不复制情绪脚本

| 截图阶段 | 可提取的方法 | 不沿用的部分 |
| --- | --- | --- |
| 闻声抬眼、脸部放松 | 先有声源刺激，视线找到目标，头部与身体自然跟随，原有紧张随认出对方而改变 | 不要求每次都眼先头后，不强制目光直撞摄影机，不新增笑纹或身份皮肤标记 |
| 偏头、单侧笑意 | 延续前一动作的余势，局部变化可体现关系中的试探或自我控制 | 不写固定10度，不把歪头或单侧笑注册为得意的固定公式 |
| 笑意停住、视线回避 | 刺激改变当下任务后，先前状态可以中止并留下残余；视线有实际对象 | 不机械缩脖、埋脸、咬唇，不为了写实堆叠肌肉、皱纹和下巴皮肤小坑 |
| 重新面对对方并开口 | 当前任务从压住情绪转向回应，松开唇部，接原定台词 | 剔除深吸冷气、胸肩明显起伏、重重眨眼；不搬用截图问候台词，不把每次开口都写成释怀 |

截图每两秒换情绪是原示例的组织，不是通用时间表。新剧情可以在一个情绪状态内持续变化，也可以让未释放的张力跨镜保留。普通眨眼和呼吸不必逐次安排。

## 导演设计顺序

先明确人物此刻想完成什么、看向谁或什么、试图控制什么。只在真实剧情刺激处设计主要变化，必要时加支持动作。头转、肩线、手指和嘴唇是可选表达通道，不要求每镜全配齐。

动作链可用“起始状态 → 刺激 → 可见变化 → 当前行动 → 剩余状态”核对，但不要把链条逐格复制成演员必须按节拍表演的五步。变化可以只出现一次，随后在同镜或下镜中持续。

软组织是动作的可见结果，例如嘴角稍松时面颊随之轻抬；不是额外主动控制任务。只描述当前景别、方向与焦点实际能看到的变化。不要强制毫米级肌肉运动、精确头转角度、全脸同步启动或每两秒一个新标签。

## 用户明确的禁用情绪表达

情绪表达不使用“倒吸一口凉气”、明显抽气、胸肩大幅起伏、惊呼式喘息，以及为惊恐/委屈添加的瞪眼、颤唇或全身颤抖套路。原稿已有这类夸张表演，也须按当前审美重新设计，不能用“原稿如此”免检。原定语言仍逐字保留；不因删夸张非语言声而删台词。

真实跑动、疼痛或受力需要的生理呼吸另按剧情表达，不自动夸大为情绪特写；安静对话的呼吸保持低弱，不额外制造喘词或抽泣。生成正文优先写需要发生的实际行为，避免长串禁词反复唤起被禁动作；审核记录负责说明排除理由。

## 83-2的实际转译例

原段的委屈和恐惧不照搬为剧烈反应。看到姐姐后，Renata原有肩线缓慢落下一点，目光留在姐姐脸上；放低信封、把话交代清楚。Vera看向左脸伤处，接稳信封后用空出的左手触伤，再扶肩背。情绪变化推动交接与进屋，不另插一次得救式松垮或大喘气。

这只是本场行动设计，不把“肩线下降”变成所有人物害怕后的固定反应。两句原定西语各发声一次，切镜只改变画面；同手持信封与触脸的冲突必须在表演设计时解决。

## 审核证据

核：刺激来自哪里，人物要做什么；遮住情绪词后动作是否可执行；视角能否读到；是否重复触发；是否说话同时紧闭嘴唇；持物的手能否完成动作；声音是否放大同一次呼吸。记录具体原句、改句和残留状态。没有真实视频时只报告文本检查，不把研究识别工具、设备名或描述密度当成效果已验证。
