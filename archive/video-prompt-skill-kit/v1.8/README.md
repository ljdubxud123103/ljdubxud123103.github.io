# 视频分镜 Skill＋完整 Loop＋GitHub资料包

版本：v1.8｜2026-10-29

## 包含什么

- SKILL.md：完整主Skill，含九仓库强制加载门禁及最新表演授权。
- LOOP.md：从当前主Skill同源提取的完整审核入口，非旧版Loop。
- REPOSITORIES.json：9仓库URL、commit、原文件路径、用途校验信息。
- REPOSITORY_FILES.json：完整源码快照的逐文件校验清单。
- repositories/：9个固定提交的源码快照，未执行第三方脚本。
- licenses/：各仓库根目录许可证副本，原文件仍保留于源码内。
- tools/：本包自编的离线校验和阅读分块工具，只使用Python标准库。
- templates/：加载回执与审核记录模板，默认均为未执行。
- audit/：方法来源、对抗复核与此次打包验证记录。

## 开始使用

云端已注册旧skill不会因下载或Git提交自动更新；在使用平台替换为本包内容并保留依赖相对路径。包内主Skill与Loop作为当前权威，旧云端规则不重新拼接。


先看SOURCE_LOADING.md。所有必读文件真实加载完成前，不使用Skill生成或正式审核。

“加载仓库”指读取指定原文件并应用方法，不是安装或执行研究程序。无需为了写提示词安装CUDA、模型权重或实验数据。OpenFace等第三方仓库有特定许可，源码归档不表示部署许可。

完整源码在专用skill-kit-full-v1.7分支及对应Release标签，main分支保持轻量阅读版。阅读包保留全部必读原文件，不替代完整源码归档。
