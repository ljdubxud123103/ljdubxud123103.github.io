开源调研与二次开发决策

针对四个新问题（「最近」卡死、首页视觉、色轮安置、色卡下载、详情页滑动切换）的根因诊断，GitHub 开源项目调研，以及直接用 / 二次开发 / 自研的最终建议。

RECOMMENDATION · 最终建议
基于现有 CinePalette 继续二次开发，不建议换用任何开源项目。
核心需求已完成约 80%：公网 PWA 部署、1214 张图色彩数据、色调检索管线。本轮仅剩 1 个 bug 修复 + 3 个交互增强，合计半天工作量。最接近的活跃项目 Cinekive 是重型桌面 AI 应用，方向与「手机随时打开」相反。
01 · DIAGNOSIS

四个问题的根因

BUG · 卡死根因已定位

「最近」页无限重渲染

useAppStore(s => s.getRecentScreenshots()) 在 selector 内调用函数，每次返回新数组引用。Zustand v5 基于 useSyncExternalStore，快照不稳定 → React 19 陷入渲染循环 → 页面卡死。首页 getFilteredScreenshots() 埋着同一颗雷。修法：订阅原始 state + useMemo 派生。

UX · 视觉降权

色轮常驻左栏喧宾夺主

48px 常驻色轮占据视线但不总是被使用。解法：改为顶部横向全宽色带（8–10px 高），像一条安静的彩虹基准线横在搜索栏下。功能完整保留（拖动选色），视觉权重从「导航栏」降为「装饰性标尺」。首页因此获得完整双列宽度。

FEATURE · 纯前端实现

色卡一键下载 PNG

详情页调色板新增下载按钮：Canvas 绘制 5 色竖版色卡（色块 + HEX 标注 + 电影名 / 导演 / 年份），canvas.toBlob() 导出 PNG。零新依赖，可直接分享到微信 / 剧组群。

FEATURE · 复用现有依赖

详情页左右滑动切换

用已有的 framer-motion：图片容器 drag="x" + onDragEnd 判断阈值（±60px），向左滑切下一张、向右滑切上一张（同片序列）。零新依赖。

03 · HEAD-TO-HEAD

最强候选 Cinekive vs 现有 CinePalette

Cinekive（换用它的代价）

  • 桌面重型应用：原生引擎 ~2GB 下载，Windows 起步慢
  • 手机只能「同 WiFi 局域网 URL」——你明确要求公网随时打开
  • 核心卖点是 SigLIP AI 语义搜索（"neon night"文字找图），不是色相色轮精确检索
  • 无预置片库：需要自己导入电影/截图，我们的 1214 张 film-grab 数据不通用
  • 弃用现有全部代码（React PWA + 色彩管线 + 已部署站点）
  • 可借鉴：moodboard 画布、craft 过滤器、自有素材导入

CinePalette（继续开发的底气）

  • 已是公网 PWA：手机添加到主屏幕，任何网络随时打开
  • 1214 张截图已带 HSV 色彩数据（主色 + 5 色板），管线可增量扩片
  • 暗色放映室视觉刚按 Taste Skill 重做完毕
  • 待办仅 4 项：1 个 bug + 3 个交互增强，预估合计 3–4 小时
  • 零迁移成本：改完即推送，GitHub Pages 自动更新
04 · MVP PLAN

最简 MVP：四步改造

修复「最近」卡死~30 MIN

RecentPage / FavoritesPage / ScreenshotGrid 全部改为订阅原始 state（recentItems、movies），用 useMemo 派生列表。一次修复三处隐患。

色轮迁至顶部横向色带~1 H

删除左侧常驻栏，首页顶部（搜索栏下方）放一条 10px 高全宽渐变带，可拖动选色，选中显示游标 + 色相读数 chip。瀑布流升级为完整宽度双列，首屏更干净。

TOP SPECTRUM BAR · 拖动选色 · 视觉降权但功能保留

色卡下载 PNG~1 H

详情页调色板区加「下载色卡」按钮：Canvas 绘制竖版色卡（5 色块 + HEX + 影片信息），导出 PNG。零新依赖。

详情页滑动切换~1 H

framer-motion drag="x" 实现同片截图左右滑切，带位移动画与边界回弹；键盘 ←/→ 同步支持（桌面）。完成后构建推送，GitHub Pages 自动上线。

调研方法：GitHub API 实时核验（stars / 最后推送 / 协议 / 技术栈）+ 仓库浅克隆阅读 README。候选源：GitHub 搜索「movie screenshot color palette」「search by color self-hosted」及 topics: color-palette / palette-generator。
